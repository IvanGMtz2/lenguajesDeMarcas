Términos clave de la informática

Algorisme
Un algoritmo es un conjunto de pasos o instrucciones que se siguen para resolver un problema o llevar a cabo una tarea concreta. Es como una receta, pero para la informática.
Base de datos
Una base de datos es un sistema organizado para almacenar y gestionar información. Permite almacenar datos de forma estructurada y facilita su recuperación cuando sea necesario.
Interfaz de usuario
La interfaz de usuario es la parte de un programa o una aplicación con la que interactúa el usuario. Incluye elementos como botones, menús y ventanas que permiten controlar el software de forma intuitiva.
