Glosario

HTML
Lenguaje de marcado estandar utilizado para crear la estructura de las paginas web. Puedes aprender mas en MDN Web Docs.
W3C
Consorcio internacional que produce estandares para la World Wide Web. Mas información en la pagina del W3C.
DOM
Interfaz de programación para documentos HTML y XML que representa la pagina para que los programas puedan cambiar la estructura, estilo y contenido.
