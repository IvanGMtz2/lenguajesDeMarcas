BOX MODEL

El modelo de caja en CSS define el espacio que ocupa un elemento, incluyendo su contenido, relleno, borde y margen.

  • Contenido: Es el área donde se muestra el contenido del elemento, como texto o imágenes.
  • Relleno (Padding): Es el espacio entre el contenido y el borde del elemento. Se puede ajustar con la propiedad padding.
  • Borde (Border): Es la línea que rodea el relleno y el contenido. Se puede personalizar con la propiedad border.
  • Margen (Margin): Es el espacio exterior que separa el elemento de otros elementos. Se puede ajustar con la propiedad margin.

Unidades de Medida

En CSS, existen varias unidades de medida que se pueden utilizar para definir las dimensiones de los elementos:

  • px (píxeles): Es la unidad más común y se basa en la resolución de la pantalla.
  • % (porcentaje): Se utiliza para definir dimensiones relativas a otro elemento o al contenedor padre.
  • em: Es una unidad relativa al tamaño de fuente del elemento.
  • rem: Es una unidad relativa al tamaño de fuente del elemento raíz (html).
  • vw: Es una unidad relativa al ancho de la ventana gráfica.
  • vh: Es una unidad relativa al alto de la ventana gráfica.

Propiedades de CSS

Algunas propiedades comunes de CSS incluyen:

  • color: Define el color del texto.
  • background-color: Define el color de fondo de un elemento.
  • font-size: Define el tamaño de la fuente del texto.
  • margin: Define el espacio exterior alrededor de un elemento.
  • padding: Define el espacio interior entre el contenido y el borde de un elemento.
  • border: Define el estilo, ancho y color del borde de un elemento.

display: block; Los elementos de bloque ocupan todo el ancho disponible y comienzan en una nueva línea. Ejemplos: <div>, <p>.

display: inline; Los elementos en línea no comienzan en una nueva línea y solo ocupan el espacio necesario. Ejemplos: <span>, <a>.

display: inline-block; Los elementos en línea-bloque se comportan como elementos en línea, pero pueden tener un ancho y alto definidos. Ejemplos: <img>, <button>.

display: flex; Los elementos flexibles se comportan como elementos en línea, pero pueden tener un ancho y alto definidos. Ejemplos: <div>, <section>.

display: grid; Los elementos de cuadrícula se comportan como elementos en línea, pero pueden tener un ancho y alto definidos. Ejemplos: <div>, <section>.

display: none; Los elementos no se muestran en la página. Ejemplos: <div>, <section>.

Propiedades de CSS

Algunas propiedades comunes de CSS incluyen: overflow, box-sizing, float, flexbox

  • overflow: Controla cómo se muestra el contenido que desborda el área de un elemento. Valores comunes: visible, hidden, scroll, auto.
  • box-sizing: Define cómo se calculan las dimensiones de un elemento. Valores comunes: content-box, border-box.
  • float: Permite que un elemento se desplace hacia la izquierda o derecha dentro de su contenedor. Valores comunes: left, right, none.
  • flexbox: Permite crear diseños flexibles y responsivos. Valores comunes: display: flex, flex-direction, flex-wrap.

FLEXBOX

El modelo flexbox permite crear diseños flexibles y responsivos de manera sencilla y eficiente.

Para activar el modelo flexbox, se debe establecer la propiedad display: flex en el contenedor padre.

Algunas propiedades importantes de flexbox incluyen:

  • flex-direction: Define la dirección de los elementos flexibles dentro del contenedor. Valores: row, row-reverse, column, column-reverse.
  • justify-content: Alinea los elementos flexibles a lo largo del eje principal. Valores: flex-start, flex-end, center, space-between, space-around.
  • align-items: Alinea los elementos flexibles a lo largo del eje transversal. Valores: flex-start, flex-end, center, baseline, stretch.
  • flex-wrap: Controla si los elementos flexibles deben ajustarse a una nueva línea cuando no caben en el contenedor. Valores: nowrap, wrap, wrap-reverse.
  • align-content: Alinea las líneas flexibles a lo largo del eje transversal. Valores: flex-start, flex-end, center, space-between, space-around, stretch.
  • gap: Define el espacio entre los elementos flexibles. Valores: normal, width, height.

MEDIA QUERYS

Las media queries permiten aplicar estilos CSS específicos según las características del dispositivo o la ventana del navegador, como el ancho, la altura, la orientación o la resolución de pantalla.

Para utilizar media queries, se emplea la regla @media seguida de una condición y un bloque de estilos CSS que se aplicarán cuando se cumpla dicha condición.

Algunos ejemplos de media queries comunes incluyen:

  • @media (max-width: 600px): Aplica estilos cuando el ancho de la ventana es igual o menor a 600 píxeles.
  • @media (min-width: 601px) and (max-width: 1024px): Aplica estilos cuando el ancho de la ventana está entre 601 y 1024 píxeles.
  • @media (orientation: landscape): Aplica estilos cuando la orientación del dispositivo es horizontal.
  • @media (orientation: portrait): Aplica estilos cuando la orientación del dispositivo es vertical.

Ejemplo de media query:

        
            @media (max-width: 600px) {
                body {
                    background-color: lightblue;
                }
            }
